# Project Brief (Charter)

## What
MCP AppsKit is a TypeScript framework for building interactive MCP applications that run across both **MCP Apps** and **ChatGPT (OpenAI Apps SDK)** from a single codebase.

## Why
Provide a consistent developer experience for defining tools, middleware, plugins, UI resources, and transports while emitting platform-specific metadata automatically.

## Success criteria
- Packages build, typecheck, lint, and tests pass in CI.
- Examples demonstrate real-world usage (tool + UI + tests).

## Constraints
- Node.js >= 20
- Strict TypeScript, no `any`
- Monorepo (pnpm + Nx)
